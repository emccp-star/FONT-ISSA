# FONT ISSA — Inking Script Serif Alphabet

[![License: OFL 1.1](https://shields.io)](https://openfontlicense.org)

**FONT ISSA** (*Inking Script Serif Alphabet*) est une police de caractères calligraphique à l'encre dotée de terminaisons empattées sculptées (*Serif*) et de glyphes symboliques uniques encodés dans la Zone à Usage Privé Unicode (`U+E003` à `U+E013`).

* **Auteur & Créateur :** Jean-Patrick Larbuisson (Jemeppe-sur-Meuse, Seraing, Belgique)
* **ID de dépôt :** `202611-1ce3c8d82ae9` (Statut : Actif — Expiration : 16-11-2031)
* **Référence :** W3C/RDP Seraing Numérique `9F27JJR7+-G3Z7+-WAVscript.exty` | Hypralogy5D | Euromegacoins (`77007777 uSI`)
* **Site officiel :** [amenael.online](https://amenael.online)
* **Licence :** [SIL Open Font License, Version 1.1](OFL.txt) — **Nom Réservé (RFN) : `"ISSA"`**
