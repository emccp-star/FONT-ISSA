### Symboles Unicode principaux
* `U+E009` (`.issa-faith`) : Croix victorieuse
* `U+E010` (`.issa-scales`) : La Balance Parfaite
* `U+E011` (`.issa-peace`) : Paix du Christ
* `U+E012` (`.issa-chrisme`) : Chrisme Unifié
* `U+E013` (`.issa-seal`) : Sceau de Licence ISSA

**FONT ISSA** est une police calligraphique à l'encre avec empattements (*Serif*) et glyphes symboliques en zone privée Unicode (`U+E003` à `U+E013`).
